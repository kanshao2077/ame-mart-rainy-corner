# 雨宿り · 雨夜便利店

无界面的可交互三维微缩模型。左键拖动旋转，右键拖动平移，滚轮缩放；触屏单指旋转，双指平移和缩放。Home 键恢复初始视角。

`雨夜便利店.html` 是完整单文件，包含 Three.js、场景、人物模型、动画和全部贴图，可直接双击离线打开，无 CDN 或外部资源请求。

源代码在 `src/`，构建命令为 `pnpm build`。`pnpm preview` 在本机 4178 端口预览 `dist/index.html`。

场景包括货架商品、饮料冷柜、收银台、咖啡和关东煮、冰柜、杂志架、自动售货机、自行车、雨伞架、护栏、电线杆、街灯、斑马线、积水倒影，以及降雨、屋檐滴水、玻璃雨痕、涟漪、自动门和灯光的细微动态。

第二版改进了冷暖配色、接触阴影、抗锯齿、平滑湿地反射、柔和雨丝、成组商品陈列、包装和咖啡海报。屋顶风扇缓慢转动。

门口使用 Microsoft Rocketbox 的 Female Adult 11 成年女性三维角色：V 领收腰裙、长靴、盘发，保留完整面部贴图与手指骨骼，调整为抬手吸烟姿态，加入轻微呼吸、转头、烟头微光和烟雾。`?view=visitor` 可直接打开门口近景，无额外界面。

人物和基础站立动画来自 https://models.codelove.in/ 的压缩 GLB，原始人物库 https://github.com/microsoft/Microsoft-Rocketbox ，MIT 许可完整保存在 GLB 元数据内。网页没有署名界面或水印。
